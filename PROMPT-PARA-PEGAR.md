# El prompt para instalar tu CRM

1. Abre **Claude Code**: en la app de Claude, la pestaña **Code**.
2. Elige o crea una carpeta que **no** esté dentro de OneDrive, iCloud ni Dropbox. Por ejemplo, `C:\Users\[tu usuario]\Proyectos` (Windows) o `Proyectos` en tu carpeta de usuario (Mac).
3. Copia y pega esto:

```
Quiero instalar el CRM de ConstruIA para mi compañía.

Clona https://github.com/henderbastidasv-roofer/crm-contratista en una carpeta nueva llamada "crm" dentro de esta carpeta, entra a ella y sigue el archivo INSTALAR.md paso a paso conmigo.

No sé programar: explícame todo simple, una cosa a la vez, y nunca me pidas que pegue claves en el chat.
```

Eso es todo. Claude Code te va a hacer preguntas de tu compañía y te va a llevar a crear cada cuenta, botón por botón. Te avisa antes de cada paso importante.

**Ten a la mano:**
- tu logo;
- tus precios por square de cada paquete;
- el impuesto de tu ciudad;
- acceso a donde compraste tu dominio (GoDaddy, Namecheap, etc.);
- tu gestor de contraseñas.
